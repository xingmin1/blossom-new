## OSKernel2025-NPUcore-BLOSSOM(RISC-V + LoongArch)

## 简介

NPUcore-BLOSSOM是来自西北工业大学的三位同学基于NPUcore-lwext4框架，参考借鉴去年内核赛道优秀参赛队伍与Linux内核的诸多优秀设计，完善其内部功能实现并进行迭代升级而形成的竞赛操作系统。

## 分支介绍

- RvLaMerge——初赛仓库分支
- la_ext4_init——支持ext4文件系统的la分支
- main——rv版本的baseline
- **ForFianl——决赛线上测例及上板分支**
- ltp——适配ltp的分支
